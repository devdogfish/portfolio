# Use same-domain entry links

Audience-targeted links use the form `girke.dev/r/<opaque-code>`. An Entry Link directly renders its selected public experience, saves the validated selection in a first-party cookie for 90 days with its lifetime refreshed on visits, and then simplifies the browser URL to `girke.dev`. A newer valid Entry Link replaces the Saved Selection; a plain `girke.dev` visit reuses it; the Default Experience appears only when neither is valid. The selection changes only through another valid Entry Link, expiry, or browser cookie deletion; no visitor-facing audience switcher or reset is provided. A path is more resilient than a query parameter to tracking-parameter removal and more likely to survive plain-text résumé extraction, while keeping the main domain avoids the DNS, TLS, redirect, branding, and cross-domain cookie costs of a separate short domain. The entry routes are not authorization boundaries and expose no private data.
